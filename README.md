# datatug

Product hub for DataTug: specifications, research and roadmap. Code lives in
[`datatug-cli`](https://github.com/datatug/datatug-cli) (CLI, TUI, server),
[`datatug-core`](https://github.com/datatug/datatug-core) (engine and project model) and
[`datatug-apps`](https://github.com/datatug/datatug-apps) (web UI); marketing and
competitor research in the private `datatug/backstage` repository (`competitors/` and `marketing/`).

Start with [spec/README.md](spec/README.md) for the reading order, or go straight to:

- [Feature hierarchy](spec/product/hierarchy.md)
- [Roadmap](ROADMAP.md)
