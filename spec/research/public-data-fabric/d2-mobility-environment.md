## Bounded source probes and reproducibility

The dated observation receipts are [d2-discovery-2026-10-04.json](evidence/d2-discovery-2026-10-04.json); selected value profiles and reprobes are [d2-profile-2026-10-04.json](evidence/d2-profile-2026-10-04.json). They record exact requested URLs, UTC times, read limits, response statuses, ETags/Last-Modified where returned and SHA256 of exactly the captured bytes. A completed range response is **not** a whole-file hash. These are dated observations of mutable providers, not invented immutable provider commits. Raw captures remain private temporary review inputs; no source data dump is committed.

The area010 NaPTAN CSV contains 1,679 unique ATCOCodes and 50 empty NaptanCodes. All 1,679 locality references match the 43,900 unique NPTG locality IDs captured on 4 Oct 2026. Every area010 AdministrativeAreaCode is the string `009`; the filter is `010`, demonstrating different code namespaces and the importance of preserving leading zeros. This probe establishes a scoped physical reference observation, not nationwide quality or semantic acceptance.

The Allens GTFS sample has one agency, one route, three trips, three calendar rows, 18 stops and 30 stop_times rows. The five tested native reference paths have zero unmatched rows. `calendar_dates.txt` has a header and zero values. The agency timezone is literally `Europe/London`, service dates are feed-specific and IDs are not assumed stable between feeds. Empty presentation, parent and zone fields remain absences.

EA sample reading `-0.367` uses a stage measure with `mASD`, a datum/qualifier and 900-second period; it is not missing data or negative rainfall. POWER has explicit fill `-999`, `T2M` in C, `PRECTOTCORR` in mm/day and requested UTC dates. Ember aggregates have empty ISO3 codes, while observed Afghanistan has `AFG`; region rows are not country identities. KEV has 1,734 rows and 1,734 unique CVEIDs at catalogue 2026.10.04; one NVD CVEID matches one KEV entry. The Babergh XML header declares 880 items; only seven complete establishment nodes occurred in the captured prefix. Two crime polygons produced zero rows and are retained as counterexamples to claimed sample coverage.

Re-run the extraction against the preserved private captures:

The script verifies byte hashes before probing and performs no network access. A fresh download must be separately dated because live providers can revise data. Candidate metadata lives in the collections; the dated JSON contains extraction evidence, not a parallel catalogue.

## Demand boundaries and next review

The all-six analysis is a signal. Country/postal/date meanings offer plausible paths across several demos, but no common-person or common-organisation identity is accepted. Dirty Chinook Edinburgh and Northwind ID/country whitespace, Pubs missing author/store country, Employees' fabricated 1,024-person subset/share-alike terms, and AdventureWorks native-versus-generated IDs, opaque geometry, precision/views and uncertain currencies retain their original constraints. No country, coordinate or currency is manufactured to improve coverage. The technology examples deliberately use explicit hypothetical user schemas where the six demos offer little direct demand.

Seven new open `fabric.questions` records retain source-rights/access including weather alternatives, rail-identifier, civic freshness and spatial/time/grain work. These block affected integrations, not bounded discovery. A fresh independent reviewer should assess this PR before landing; a separate fresh Phase2 reconciler should examine proposed meanings/edges; the later portfolio architect should choose practical scenarios. Nothing in this researcher receipt advances a phase gate.
