## Provider storage, authentication and cost remain separate gates

For `bq-source-public-data` and `bq-opportunity-dual-runtime`, [Google cached-result documentation](https://docs.cloud.google.com/bigquery/docs/cached-results) says query results are materialized to destination or temporary tables. Typical temporary caching lasts approximately 24 hours, with exceptions; this is not a guaranteed maximum deletion SLA. `useQueryCache: false` disables retrieval reuse and does **not** prevent provider result-table materialization. Owned no-store headers and transient client/OVDB RAM do not satisfy the separate provider-retention authorization requirement. A free query still has this storage consequence.

[Public dataset access](https://docs.cloud.google.com/bigquery/public-data) requires an account/project; source storage and executing-project query charges are distinct. Free quota is not programme cost approval. Keep execution project unassigned, cost admission not granted, Go/JavaScript acceptance pending and direct-browser CORS/OAuth/IAM unverified. [Dry-run and maximumBytesBilled controls](https://docs.cloud.google.com/bigquery/docs/best-practices-costs) remain required later; `LIMIT` alone is not a scan-cost cap.

The next metadata-only gate is a bounded authenticated allowlist of [datasets.get](https://docs.cloud.google.com/bigquery/docs/reference/rest/v2/datasets/get) and [tables.get](https://docs.cloud.google.com/bigquery/docs/reference/rest/v2/tables/get), including native names/types/modes, location, partitioning, etag and observed metadata time. Use STORAGE_STATS/default when `lastModifiedTime` is required; BASIC excludes it. No metadata API call, query/dry run, Preview, `tabledata.list`, `bq head`, row copy, export, activation or deployment occurred in this checkpoint.

The current ECB-only inactive discovery schema cannot faithfully encode native BigQuery types/modes, locators, documented-versus-observed evidence, authentication/project/cost requirements or provider storage facts. A separately reviewed `bigquery-native` schema extension must precede canonical source publication. ModelSpec/MeaningGraph registration requires real reviewed pinned artifacts; hypothetical field descriptions are not registrations. Original research review r1 found zero blockers, one major and one minor and returned `land=no`; its historical verdict is preserved. Both findings are addressed in this addendum, while fresh review of the retained correction and all publication/execution gates remain pending.
